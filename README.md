A toaster that ejects each slice under a tiny parachute — one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, entered in make.fun's "One-Sentence Absurd Invention Pitch" bounty. The program reads the pitch from `pitch.txt`, validates it against the gate (UTF-8 text, 1–220 characters, one sentence), and writes it atomically to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
